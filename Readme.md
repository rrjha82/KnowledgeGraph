# 🚀 KnowledgeGraph

AI-powered Knowledge Graph Engine for Playwright Automation Frameworks.

---

## 📖 Overview

KnowledgeGraph analyzes Playwright automation projects using the TypeScript Compiler API and builds a semantic Knowledge Graph representing:

- 📄 Pages
- ⚙️ Methods
- 📍 Locators
- 🧪 Tests
- ✅ Assertions
- 🔗 Dependencies

The generated graph enables powerful code analysis and serves as the foundation for AI-assisted automation.

---

## ✨ Features

- AST Parsing
- Page Object Analysis
- Test Analysis
- Dependency Explorer
- Impact Analysis
- Static Analysis
- Knowledge Graph Generation
- JSON Export
- Interactive Graph Viewer
